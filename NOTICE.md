# Project provenance

This project extends DGHNN: Deep graph and hypergraph neural network for
pan-cancer related gene prediction.

- Original project: https://github.com/skytea/DGHNN
- Original paper: https://doi.org/10.1093/bioinformatics/btaf379
- PE/SE design reference: Recipe for a General, Powerful, Scalable Graph
  Transformer, NeurIPS 2022: https://arxiv.org/abs/2205.12454
- GraphGPS reference implementation: https://github.com/rampasek/GraphGPS

The PE/SE preprocessing and edge-conditioned chunked message passing in this
version are DGHNN adaptations. This repository does not claim to reproduce the
entire GraphGPS architecture or its published results.

Datasets, pretrained weights, experimental outputs, credentials, third-party
paper PDFs, and local research documents are excluded from this code release.
Consult the upstream projects and dataset providers for their applicable terms;
this notice does not grant a new license for upstream materials.
